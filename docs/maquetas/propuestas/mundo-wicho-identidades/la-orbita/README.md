# «La espiral», con el concepto mandando: la órbita (propuesta, 2026-10-25)

El intento anterior (`../espiral/`) se rechazó: era la identidad pintada sobre el esqueleto viejo de
seis pantallas, con acabado de boceto. Este parte de cero, y **la espiral es la forma de armar**.

- **Es una sola pantalla.** No hay seis páginas con cabecera, opciones y pie.
- **Las opciones de cada paso orbitan alrededor del centro:**
  - fotos reales en las proteínas;
  - esferas con color y textura en lo demás;
  - el nombre siempre del lado de afuera.
- **Al tocar una opción, viaja girando hacia el centro:** ahí se forma el sándwich, capa por capa, y
  la espiral avanza una vuelta.
- **Cuando se elige una sola** (tamaño, pan, proteína, queso), se avanza solo. Cuando se eligen
  varias (vegetales y salsas, hasta 3), hay botón para seguir.
- **En el final**, la espiral queda cerrada y girando alrededor del sándwich. Ahí aparecen las
  mejoras que existen hoy: doble proteína y doble de la última salsa, con su precio.
- **Se queda:**
  - «¿Son varios?», en el tamaño;
  - el puente a la estrella de SANDO y el secreto, en la proteína;
  - «Y además»;
  - el precio vivo en el pie.

**Archivos:**
- `orbita.template.html` es el prototipo.
- `construir.py` le mete las fuentes y las fotos, y deja un solo archivo que funciona en el celular.
- `recorrer.cjs` lo recorre, saca las capturas y graba el video.
