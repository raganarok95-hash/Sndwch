# Lo aprendido, por rol (los equipos fuera de marketing)

Igual que `docs/marketing/equipo/aprendizajes/`: cada especialista lee su archivo antes de
trabajar y agrega lo que decidió, con su porqué. Lo que dice el dueño va **con sus palabras y la
fecha**. Nada de cifras de ventas, utilidad ni caja (el repo es público).

```
- **AAAA-MM-DD · <qué>.** Dueño: «<sus palabras>». <Por qué>. <La regla que queda>.
```
