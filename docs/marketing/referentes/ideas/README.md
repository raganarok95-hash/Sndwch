# Banco de ideas (anuncios y posts que le gustaron a Ezra)

Encargo fijo del dueño (2026-11-10): «Algunas publicidades que vi y son interesantes necesito que haya también un
hilo o dentro de los ya creados para alimentar a marketing de ideas interesantes que vea que podemos analizar y
replicar o mejorar». Lo hace el hilo «Equipo de investigación».

Cada vez que Ezra manda capturas, se escribe aquí un archivo `AAAA-MM-DD-<tema>.md` con:

1. **Qué es** cada pieza (marca, formato, láminas, música, números visibles a la fecha de la captura).
2. **Por qué funciona**: la mecánica, no la frase.
3. **Cómo lo hacemos con SANDO y WICHO**: se toma la mecánica y se cambia la frase, el chiste y la imagen. Nunca se
   copia una marca ni su texto.
4. **Si ya está gastada** (cuántas marcas la usan esa misma semana).

Las capturas no se suben a este repo (es público y salen perfiles ajenos): quedan en la carpeta privada del
proyecto, `marketing/ideas/<fecha>-capturas/`.

La rutina de reels y la agencia del lunes leen esta carpeta junto con `../`.
