# Lo aprendido, por rol

Cada especialista lee **su** archivo antes de trabajar (`reglas-sndwch`) y agrega lo que decidió
con su porqué. Lo que dice el dueño va **con sus palabras y la fecha**. El orquestador lo anota
cuando el dueño aprueba, rechaza o corrige algo.

Formato de cada entrada:
```
- **AAAA-MM-DD · <qué>.** Dueño: «<sus palabras>». <Por qué, en una frase>. <La regla que queda>.
```
Una entrada que el dato contradice (el Analista, cada mes) se tacha con su fecha, no se borra.
